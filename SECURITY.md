# Security policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately to
`info@aiagentcycle.com`. Include the affected endpoint or component, a concise
description, reproduction steps, and the potential impact. Please do not open a
public GitHub issue for an unpatched vulnerability.

AIAgentCycle will acknowledge the report, investigate it, and coordinate any
necessary remediation and disclosure with the reporter.

## Scope

This policy covers the AIAgentCycle MCP server, its public Streamable HTTP
endpoint at `https://mcp.aiagentcycle.com/mcp`, and the deployment files in this
repository.
